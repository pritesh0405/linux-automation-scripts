# Linux Automation Scripts

Practical Bash automation scripts inspired by real-world Linux administration, monitoring, maintenance, and automation tasks.

## Current Scripts

### Monitoring

| Script | Description |
|----------|-------------|
| disk_monitor.sh | Monitor filesystem utilization and alert on threshold breaches |
| system_health_check.sh | Generate overall server health report |
| process_monitor.sh | Monitor Linux processes |
| service_monitor.sh | Monitor Linux services |


### Log Management

| Script | Description |
|----------|-------------|
| log_cleanup.sh | Remove old log files based on retention policy |

### User Management

| Script | Description |
|----------|-------------|
| create_user.sh | Automate Linux user creation |
